## 👀 서비스 소개
![표지](./문서/readme_images/표지.png)
* 서비스명:  YOLO11 기반 공항 활주로 실시간 이상물체 탐지 및 알림 서비스
* 서비스설명: 이상물체 탐지 시스템 구축이 어려운 지방공항의 안전사고 예방과 인력난을 해결하기 위한, 공항 CCTV 인프라를 활용한 이상물체 실시간 탐지 자동화 시스템
<br>

## ⛏ 구현 내용
![사용언어 및 도구](./문서/readme_images/사용_언어_및_도구.png)
<br>
### 1. Frontend
- 사용 언어 : HTML, CSS, TypeScript
- Framework : React (vite)

### 2. Backend
- 사용 언어 : Java JDK 21
- Framework : Spring Boot

### 3. AI Server
- 사용 언어 : Python 3.10
- AI 모델 : YOLOv11 (fine-tuned)

### 4. Database
- RDBMS : MySQL

### 5. Server
- Cloud : Naver Cloud Platform
- OS : Ubuntu 24.04
- Web Server : Nginx
- WAS Server : Tomcat
- AI Server : Flask
- 컨테이너 : Docker
